Task 5: Create a java pogram to print the String in reverse order.
import java.util.Scanner;
class String_reversal{
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a String: ");

        String str = sc.next();
        String new_str = "";

        for(int i=str.length()-1;i>=0; i--){
            new_str+= str.charAt(i);
        }  
        System.out.println("String after reversal: "+ new_str);
        sc.close();
    }
}

output: 
Enter a String: 
Hello 
String after reversal: olleH

Understanding:
Static variables and methods are allocated memory in the compile time. We can modify or assign the values of a static variable in the runtime. We can access the static variable by ClassName.static_variable_name, it is a shared variable among all the class objects.

Task 12: What are access modifiers in java … give detailed explanation?
Access modifiers in java helps to give different permission or access to variables and methods in different scopes of the program, of the project structure and through out the entire system.
There are 4 access modifiers in java. private, protected, public and default. Private elements can be only accessed within the class scope, protected ones can be used throughout the inheritance level (parent and its child classes). Public variables and methods can be accessed from anywhere. Default is similar to public, but it can be only accessed within the same package.

import java.util.*;
public class For_each {
    public static void main(String[] args) {
        ArrayList <String>ls = new ArrayList<>();
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter 3 Employee Names:");

            ls.add(str);
        }
        System.out.println("The input names are as follows: ");

Wap to show the difference between break and continue. 
Use for loop to show the diff

public class For_each {
    public static void main(String[] args) {
        for(int i=0;i<10; i++){
            if (i==3){
                break;
            }
            System.out.print(i+" ");
        }
        System.out.println("loop exited when i became 3");
        
        for(int i=0;i<10; i++){
            if (i>2 && i<7){
                continue;
            }
            System.out.print(i+" ");
        }
        System.out.println("loop skipped the values between 2 and 7");
        
    }
}

output:
0 1 2 loop exited when i became 3
0 1 2 7 8 9 loop skipped the values between 2 and 7
