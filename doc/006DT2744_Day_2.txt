What do you understand by HTTP and HTTPS?
HTTP stands for Hyper Text Transfer Protocol and HTTPS stands Hyper Text Transfer Protocol Secure.
These are methods or protocols used to transfer data across the internet.


Task 14:
What are the methods in HTTP?
HTTP has several methods such as GET, POST, PUT, PATCH, DELETE, Query


Task 15:
Give few status codes in http.
200 -> success, 201 -> successfully created, 404 -> Not Found, 400 Bad Request, 500 -> Internal Server Error

Task 16:
What do you understand by Header in http request?
In a http request, header is the part containing source and destination ip addresses, meta data about the request, it can contains encryption keys etc.
