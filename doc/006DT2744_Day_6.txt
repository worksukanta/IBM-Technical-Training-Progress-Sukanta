Task 7: What is JUnit?
JUnit is a unit testing tool/Framework for java programs. It is mainly used to run test cases for
individual methods or classes to ensure the logic is right and giving desired results.


Task 8: List down the annotations of JUnit 5.
Core testing annotations: @Test, @ParameterizedTest, @RepeatedTest
Lifecycle annotations: @BeforeEach, @AfterEach, @BeforeAll, @AfterAll
Configuration and filtering annotations: @Disabled, @DisplayName, @Tag

Task 9: Difference Between JUnit 5 and JUnit 4
JUnit 5 works on Java 8 and later version, JUnit 4 works on versions previous of java8.
JUnit 5 supports lambda expressions, JUnit 4 does not.
Name of Annotations got modified in Junit 5, previously annotations were more focused on class,
(e.g. BeforeClass, AfterClass etc), in JUnit5 it renamed to -All, more generalized one.

Task 10: What is JUnit Test Suite?
JUnit Test Suite is nothing but the collections of multiple test JUnit test cases groupped together,
so that it can be executed together as a batch.

Task 11: What is Junit Vintage?
JUnit Vintage is a Test Engine to run JUnit 4 and previous version JUnit 4 codes.
for JUnit 5, JUnit Jupiter is used.

Task 15: What are default and static methods in interfaces
default methods in interfaces are the methods which we are not abstract, i.e. you can define the
methods within the interface itself.
static methods are similar to default methods, you can define it within the interface. For static 
interface methods, we cannot override it (not inheritable), we do not need to create object to call that method, we
can directly call the static method by InterfaceName.static_method().
