Task 12: What is auto boxing and auto unboxing
Boxing: Autoboxing is the automatic conversion that the Java compiler makes between a primitive type 
and its corresponding object wrapper class.
Unboxing: Wrapper Class to Primitive Data Types. 
// Example in an expression
Integer x = 50; // Autoboxing
Integer y = 20; // Autoboxing
int sum = x + y; // Unboxing happens to both x and y so they can be added together
