Task 1: What is spring data JPA?
Spring Data JPA is a framework within the Spring ecosystem that simplifies data access in Java 
applications by providing an abstraction layer over the Java Persistence API (JPA).
Instead of writing complex, repetitive SQL queries or manually managing database sessions, it 
allows developers to interact with relational databases using standard Java objects through 
Object-Relational Mapping (ORM).

Task 2: What are the key features of Spring data JPA?
Repository Abstraction: By extending interfaces like JpaRepository, Spring automatically generates 
common database actions (saving, updating, deleting, and finding data) at runtime without any 
custom implementation code.

Derived Query Methods: You can define custom database searches simply by naming your interface 
methods. For example, declaring List<User> findByLastNameAndAge(String name, int age) prompts 
Spring to write the query for you automatically.

Custom Queries: For highly complex logic, you can easily attach hand-written Java Persistence Query 
Language (JPQL) or native SQL queries using @Query annotations.

Built-in Pagination & Sorting: It handles sorting and chunking massive datasets natively via 
specific method arguments (Pageable and Sort), reducing the manual math required for multi-page UI 
views.
---------------------------------
Task 3: What are core components of Spring data JPA?
1. The Repository Interfaces Hierarchy: under which we have, 
CrudRepository: Provides basic Create, Read, Update, and Delete methods.
PagingAndSortingRepository: Adds features for sorting data and fetching pages.
JpaRepository: Combines both and adds JPA-specific features like batch deletion.

2. Repository ProxyRuntime Implementation: 
Spring automatically generates the actual class implementation for your repository interfaces at 
startup using Java Dynamic Proxies.

3. Query Creation Mechanisms
Derived Queries: Generates database queries automatically from method names (e.g., findByEmail).
@Query Annotation: Executes custom JPQL or native SQL queries mapped directly to a method.
Specification API: Builds dynamic, reusable query filters using programmatic criteria.

4. Infrastructure Support
Auditing: Automatically populates timestamps and user tracking data (e.g., @CreatedDate).
Bootstrap: Automated configuration (via @EnableJpaRepositories) that hooks your repositories into 
the Spring lifecycle.
