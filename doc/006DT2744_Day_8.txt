Task 04: What is Dependency Injection?
Dependency Injection is software design pattern, where rather than creating objects directly with
new keyword (or other traditional OOP object creation process), we create objects from external
source (e.g. from context xml in spring). It provides another layer of security/abstraction. It
helps to achieve loose coupling, better testibility and cleaner code maintenance.
